# 二次元コードメーカー

入力した文字列を二次元コードに変換して表示する、シンプルなAndroidアプリです。

## 作った理由

ちょっとした文字列を渡したいだけなのに、そのために連絡先を交換するのは面倒。
画面を見せるだけで済ませたかったので作りました。完全に自分用です。

## 機能

- 入力した文字列を二次元コードに変換して表示
- ライトテーマ / ダークテーマ対応

### 今後追加予定

- 二次元コードの読み取り機能

## 動作環境

- Android 8.0（API 26）以上
